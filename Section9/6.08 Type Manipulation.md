


### 타입 조작 개요
- 배경
	- 템플릿 메타프로그래밍에서 주로 사용됩니다.
	- 컴파일 시간에 타입과 상수표현식을 다루기위해 고안된 기법입니다.
	- 타입조작으로 해결할수 있는 문제는 다음과 같을 수 있습니다.
		- 타입 안정성 확보 
		- 코드 중복 제거
		- 성능 최적화
		- 코드 재사용성 증가
		- 유연성 제공
			- 다양한 타입에 대해 특수화된 동작을 정의 가능

- C++에서 타입 트레이트를 사용한 타입 조작(Type Manipulation)은 프로그래밍적으로 타입의 속성을 변경할 수 있게 해주는  기능입니다.
- `type traits`를 사용하여 타입 필드를 사용하여, 타입을 조작할 수 있게합니다.

### 예제: 정수에서 부호 없는 타입 생성
```C++ 
#include <type_traits>
using U = typename std::make_unsigned<int>::type;
// 'typename'이 필요한 이유는 다음 강의에서 설명
U y = 5; // unsigned
```

C++14에서는 타입 트레이트의 **가독성**을 향상시키기 위해 `std::make_unsigned_t<T>`와 같은 유틸리티를 제공합니다. 이는 `typename std::make_unsigned<T>::type`의 단순화된 형태입니다.
#### signed와 unsigned 타입

- **make_signed**: 서명된 타입을 만듭니다. 예: `unsigned int`를 `int`로 변환
- **make_unsigned**: 서명이 없는 타입을 만듭니다. 예: `int`를 `unsigned int`로 변환

#### 포인터와 참조 (Pointers and References)

- **remove_pointer**: 포인터를 제거합니다. 예: `T*` → `T`
- **remove_reference**: 참조를 제거합니다. 예: `T&` → `T`
- **add_pointer**: 포인터를 추가합니다. 예: `T` → `T*`
- **add_lvalue_reference**: lvalue 참조를 추가합니다. 예: `T` → `T&`

#### const 지정자 (Const Specifiers)

- **remove_const**: const를 제거합니다. 예: `const T` → `T`
- **add_const**: const를 추가합니다. 예: `T` → `const T`

#### 기타 타입 변환 (Other Type Transformations)

- **common_type<T, R>**: `T`와 `R` 사이의 공통 타입을 반환합니다.
- **conditional<pred, T, R>**: `pred`가 참이면 `T`, 거짓이면 `R`을 반환합니다.
- **decay<T>**: 값으로 전달된 함수 매개변수와 동일한 타입을 반환합니다.
