# - Class Template
- 클래스 템플릿은 함수 템플릿과 유사하게, 클래스의 패밀리를 만들기 위해 사용합니다. 

#### 1.1 클래스 템플릿의 기본적인 사용
```C++
template<typename T>
struct A {
    // class template (typename template)
    T x = 0;
};

template<int N1>
struct B {
    // class template (numeric template), 정수 템플
    int N = N1;
};

A<int> a1; // a1.x is int x = 0
A<float> a2; // a2.x is float x = 0.0f
B<1> b1; // b1.N is 1
B<2> b2; // b2.N is 2

```


#### 1.2 클래스 템플릿 특수화
- 클래스 템플릿은 함수 템플릿과는 다르게 **부분적**으로 특수화 할 수 있습니다.
- 모든 클래스 특수화 ( 부분 특수화와 전체 특수화 모두)는 완전히 새로운 클래스이며, 일반 템플릿 클래스와는 아무것도 공유하지 않습니다.
- 아래 세가지 예제를 통해, 다양한 타입과 값을 유연하게 처리하는 방식을 알 수 있습니다. 
```C++
// 기본 클래스 템플릿
template<typename T, typename R>
struct A {
    T x;
    R y;
};

// 부분 특수화
template<typename T>
struct A<T, int> {
    T x;
    int y;
};

// 전체 특수화
template<>
struct A<float, int> {
    float x;
    int y;
    void print() {
        std::cout << "Specialized for float and int\n";
    }
};
```

- 관련예제 2
- `a1.y;`와 `a2.x`의 경우 제네릭 템플릿이 아니므로 컴파일 에러가 발생합니다. 
```C++
template<typename T, typename R>
struct A {
    // GENERIC class template
    T x;
};

template<typename T>
struct A<T, int> {
    // PARTIAL specialization
    T y;
};

A<float, float> a1; // ok, generic template
// a1.x; // ok
// a1.y; // compile error

A<float, int> a2; // ok, partial specialization
// a2.y; // ok
// a2.x; // compile error

```
#### 1.3`is_same`Type Trait 관련 예제
```C++
// 기본 템플릿: 다른 타입일 때 false
template<typename T, typename R>
struct is_same {
    static constexpr bool value = false;
};

// 부분 특수화: 같은 타입일 때 true
template<typename T>
struct is_same<T, T> {
    static constexpr bool value = true;
};

int main() {
    std::cout << is_same<int, char>::value << "\n"; // 출력: 0 (false)
    std::cout << is_same<float, float>::value << "\n"; // 출력: 1 (true)
}

```
