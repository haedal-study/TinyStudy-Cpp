**C++20 Concepts**
- 6.18(~74/80) : Overview | concept Keyword | reuquires Clause

### C++20
- C++ 20에서 템플릿의 제약조건을 정의하고강제하는 기능으로 `concepts`를 도입했습니다.
- `concepts`는 템플릿 인자에 대한 요구사항을 명시하여, 컴파일 타임에 인자 검증을 수행할 수 있습니다. 
- 이는 SFINAE와 비교하여 다음과같은 장점이 있습니다.
	- `concepts`가  더 읽고 쓰기 쉽습니다
	- 컴파일 타임 오류메세지가 더 명확합니다.
	- 컴파일 시간을 단축시킵니다.
- 주요키워드는 다음과 같습니다.
- `concept` 개념을 정의하기위한 키워드입니다.
- `requires` 제약 조건을 명시하기 위한 키워드입니다. 


### 사용예시
산술타입만 허용하는 함수를 정의하고싶다고 가정합니다.
```C++
template<typename T>
T add(T valueA, T valueB) {
    return valueA + valueB;
}

struct A {};

int main() {
    add(3, 4); // ok
    // add(A{}, A{}); // 지원되지 않음
    return 0;
}

```

아래와 같이 SFINAE를 이용해서 해결할수있지만 번잡하고 장황합니다
```C++
template<typename T>
std::enable_if_t<std::is_arithmetic_v<T>, T> add(T valueA, T valueB) {
    return valueA + valueB;
}

```

concepts를 사용하여 더 간결하고 가독성이 좋은 코드로 만들 수 있습니다
```C++
#include <concepts>
#include <iostream>

// 산술 타입에 대한 Concept 정의
template<typename T>
concept Arithmetic = std::is_arithmetic_v<T>;

// 산술 타입만을 허용하는 함수 정의
template<Arithmetic T>
T add(T valueA, T valueB) {
    return valueA + valueB;
}

struct A {};

int main() {
    std::cout << add(3, 4) << std::endl; // ok
    // std::cout << add(A{}, A{}) << std::endl; // 컴파일 오류
    return 0;
}

```

### `concept` keyword
- 템플릿 인자에 대한 제약조건을 설정합니다.
기본문법은 아래와 같습니다
```C++
template <typename T>
concept ConceptName = [compile-time boolean expression];

```
예시
1. Arithmetic 타입에 대한 concept 정의
```C++
template<typename T>
concept Arithmetic = std::is_arithmetic_v<T>;

```
2. 템플릿 인자에 제약조건 적용
```C++
template<Arithmetic T>
T add(T valueA, T valueB) {
    return valueA + valueB;
}

```

3. `auto` 타입 추론에 제약조건 적용
```C++
auto add(Arithmetic auto valueA, Arithmetic auto valueB) {
    return valueA + valueB;
}

```

4. 위내용 정리
```C++
#include <concepts>
#include <iostream>

// Arithmetic 타입에 대한 Concept 정의
template<typename T>
concept Arithmetic = std::is_arithmetic_v<T>;

// 템플릿 인자에 제약 조건을 적용한 함수
template<Arithmetic T>
T add(T valueA, T valueB) {
    return valueA + valueB;
}

// auto 타입 추론에 제약 조건을 적용한 함수
auto add(Arithmetic auto valueA, Arithmetic auto valueB) {
    return valueA + valueB;
}

struct A {};

int main() {
    std::cout << add(3, 4) << std::endl; // ok: 7
    std::cout << add(2.5, 3.5) << std::endl; // ok: 6.0
    // std::cout << add(A{}, A{}) << std::endl; // 컴파일 오류: A는 Arithmetic 타입이 아님

    return 0;
}

```
