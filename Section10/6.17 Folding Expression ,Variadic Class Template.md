### Folding Expression 
- `C++17`이후로 도입되었으며, 
- 템플릿 파라미터 팩을 이항 연산자(binary operator)를 사용하여 접는(fold) 연산을 수행합니다.
- 코드의 간결성과 가독성을 향상시킵니다.
- 유니언 폴드방식과, 바이너리 표현식을 각각 다음과 같습니다. 
```C++
template<typename... Args>
auto add_unary(Args... args) {
    // 유니언(fold) 표현식
    return (... + args); // 예: 1 + 2.0f + 3ull
}


template<typename... Args>
auto add_binary(Args... args) {
    // 바이너리(fold) 표현식
    return (1 + ... + args); // 예: 1 + 1 + 2.0f + 3ull
}


```

```C++
#include <iostream>

template<typename... Args>
auto add_unary(Args... args) {
    return (... + args); // 모든 인자를 더하는 단항 접기
}

int main() {
    std::cout << add_unary(1, 2.0f, 3ll) << std::endl; // 출력: 6.0f (float)
    return 0;
}

```
### 예제 
```C++
#include <iostream>

// 유니언(fold) 예제
template<typename... Args>
auto add_unary(Args... args) {
    return (... + args);
}

// 바이너리(fold) 예제
template<typename... Args>
auto add_binary(Args... args) {
    return (1 + ... + args);
}

int main() {
    std::cout << add_unary(1, 2.0f, 3ll) << std::endl; // 출력: 6.0f (float)
    std::cout << add_binary(1, 2.0f, 3ll) << std::endl; // 출력: 7.0f (float)
    return 0;
}

```

- add_square 예제를 folding expression을 사용하여 더 간단하게 작성할 수 있습니다

```C++
template<typename T>
T square(T value) {
    return value * value;
}

template<typename... TArgs>
auto add_square(TArgs... args) {
    return (square(args) + ...); // 각 인자에 square()를 적용하고 모두 더함
}

int main() {
    std::cout << add_square(2, 2, 3.0f) << std::endl; // 출력: 17.0f
    return 0;
}

```


### Variadic Template을 사용한 클래스
- 아래예제는 `vardiadic template`을 사용하여, 재귀적으로 데이터를 처리하는 클래스를 정의하는 방법을 보여줍니다.
- `Add`라는 클래스 템플릿을 사용하여 여러 정수 인자를 받아 이를 모두 더는 구조를 구현합니다.
```C++
template<int... NArgs> struct Add; // 데이터 구조 선언

template<int N1, int N2>
struct Add<N1, N2> { // 기본 케이스
    static constexpr int value = N1 + N2;
};

template<int N1, int... NArgs>
struct Add<N1, NArgs...> { // 재귀 케이스
    static constexpr int value = N1 + Add<NArgs...>::value;
};

// 사용 예제
int main() {
    constexpr int result = Add<2, 3, 4>::value; // 결과: 9
    std::cout << result << std::endl;
    return 0;
}

```

- 재귀적구조 
```C++
template<typename... TArgs> struct Tuple; // 데이터 구조 선언

template<typename T>
struct Tuple<T> { // 기본 케이스
    T value; // 단일 파라미터 특수화
};

template<typename T, typename... TArgs>
struct Tuple<T, TArgs...> { // 재귀 케이스
    T value; // 첫 번째 값
    Tuple<TArgs...> tail; // 나머지 값들을 포함하는 재귀적인 튜플
};

// 사용 예제
int main() {
    Tuple<int, float, char> t1 { 2, 2.0, 'a' };
    std::cout << t1.value << std::endl; // 2
    std::cout << t1.tail.value << std::endl; // 2.0
    std::cout << t1.tail.tail.value << std::endl; // 'a'
    return 0;
}

```

#### Variadic Template and Class Specialization 
- 클래스 특수화를 같이 사용하여, 함수의 인개수를 컴파일 타임에 구하는 방법을 보여줍다.
- 다양한 함수 타입(포인터,참조,객체) 에 대해 인자 개수를 계산하는 템플릿 클래스 `GetArity`를 정의합니다.
```C++
// 기본 템플릿 선언
template <typename T> struct GetArity;

// 함수 포인터에 대한 특수화
template<typename R, typename... Args>
struct GetArity<R(*)(Args...)> {
    static constexpr int value = sizeof...(Args);
};

// 함수 참조에 대한 특수화
template<typename R, typename... Args>
struct GetArity<R(&)(Args...)> {
    static constexpr int value = sizeof...(Args);
};

// 함수 객체에 대한 특수화
template<typename R, typename... Args>
struct GetArity<R(Args...)> {
    static constexpr int value = sizeof...(Args);
};

```
- 인자 개수 사용 예시
```C++
void f(int, char, double) {}

int main() {
    // 함수 객체
     int arity1 = GetArity<decltype(f)>::value; // 결과: 3

    auto& g = f;
    // 함수 참조
     int arity2 = GetArity<decltype(g)>::value; // 결과: 3
     int arity3 = GetArity<decltype((f))>::value; // 결과: 3

    auto* h = f;
    // 함수 포인터
     int arity4 = GetArity<decltype(h)>::value; // 결과: 3

    std::cout << arity1 << ", " << arity2 << ", " << arity3 << ", " << arity4 << std::endl;

    return 0;
}

```

- 람다 함수와  operator()의 인자갯수 구하기
		- `R(C::*)(Args...)`로 클래스 멤버 함수에 대한 특수화를 진행합니다. 
```C++
template <typename T> struct GetArity;

// 클래스 멤버 함수의 인자 개수 구하기
template<typename R, typename C, typename... Args>
struct GetArity<R(C::*)(Args...)> {
    static constexpr int value = sizeof...(Args);
};

// const 클래스 멤버 함수의 인자 개수 구하기
template<typename R, typename C, typename... Args>
struct GetArity<R(C::*)(Args...) const> {
    static constexpr int value = sizeof...(Args);
};

struct A {
    void operator()(char, char) {}
    void operator()(char, char) const {}
};

// 사용 예제
int main() {
    // 함수 객체의 인자 개수 구하기
    constexpr int arity1 = GetArity<decltype(&A::operator())>::value; // 2
    constexpr int arity2 = GetArity<decltype(&A::operator() const)>::value; // 2

    std::cout << arity1 << ", " << arity2 << std::endl;

    return 0;
}

```
