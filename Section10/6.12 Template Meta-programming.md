- 6.12(~36/80) : Template Meta-programming

### What's Template Meta-Programmmig?
- 템플릿 메타 프로그래밍이란, 컴퓨터 프로그램이 다른 프로그램을 데이터로써 처리할 수 있는 능력을 의미합니다.
- 이는 프로그램이 다른 프로그램을 읽고, 생성하고, 분석하고, 변환하거나 실행 중에 자기 자신을 수정할 수 있음을 의미합니다.
- C++ 템플릿 시스템을 사용하여 컴파일 타임에 계산을 수행하는 것을 템플릿 메타 프로그래밍이라고 합니다.
- 템플릿 메타 프로그래밍에서는 컴파일 타임 상수, 데이터 구조 및 완전함수등이 포함됩니다.

### Meta-Programming의 특징 
- **속도**
	- 템플릿 메타 프로그래밍은 컴파일 시간에 계산되며, 런타임에는 아무것도 계산되지 않습니다. 따라서 런타임 성능이 매우 빠릅니다.
- **튜링(truing) 완전성**
	- 템플릿 메타 프로그래밍은 튜링 완전합니다. 이는 표준 프로그래밍 언어가 수행할 수 있는모든 작업을 표현할 수 있음을 의미합니다.
	- 튜링 기계가 수행할 수 있는 모든 계산을 표현할 수 있으며, 조건,반복,재귀등을 포함한 모든 논리구조를 지원합니다.
	- 참고- 튜링기계
		- Alan Truing이라는 인공지능 연구, 현대컴퓨터 과학 기초 마련업적 기반
		- 그가 튜링기계 개념을 제안
			- 무한한 테이프 (입력 값과 중간계산 결과를 저장할 수 있는 무한한 길이의 테잎)
			- 읽기/쓰기 머리 : 테이프위를 이동하여 읽거나 쓰는 장치
			- 상태 레지스터 : 현재 상태를 저장하는 장치
			- 상태 전이 함수: 현재 상태와 현재 읽고 있는 기호에 따라 다음 상태, 기호쓰기, 이동방향을 결정
		- 튜링완전성
			- 튜링 완전성은 특정 계산 모델이나 프로그래밍 언어가 튜링 기계가 수행할 수 있는 모든 계산을 수행할 수 있음을 의미합니다. 즉, 튜링 완전한 시스템은 다음과 같은 조건을 만족해야 합니다:
				1. **임의의 계산**: 조건문, 반복문, 함수 호출 등을 포함하여 임의의 복잡한 계산을 표현할 수 있어야 합니다.
				2. **무한 루프**: 무한 루프를 만들 수 있어야 합니다. 이는 모든 계산 모델이 계산을 중단하지 않을 가능성을 허용해야 함을 의미합니다.
- **긴 컴파일시간**
	- 탬플릿 재귀는 컴파일 시간을 크게 증가시키고. 표준 코드 컴파일보다 훨씬 더 많은 메모리를 필요로 합니다.
- **복잡성**
	- 모든 것이 재귀적으로 표현되므로 코드가 읽기 어렵고, 작성하기 어렵습니다. 디버깅 또만 매우 어렵습니다. 




### 예제 : 팩토리얼 계산을 위한 메타프로그래밍
``` C++
// 템플릿 메타프로그래밍을 사용한 팩토리얼 계산

// 일반 템플릿: 재귀 단계
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};

// 특수화된 템플릿: 기본 사례
template<>
struct Factorial<0> {
    static constexpr int value = 1;
};

int main() {
    // 팩토리얼 계산 결과를 컴파일 타임에 얻음
    constexpr int x = Factorial<5>::value; // Factorial<5>::value는 120

    // 이 코드는 무한 재귀로 인해 컴파일 타임 에러를 발생시킴
    // int y = Factorial<-1>::value; // Infinite recursion :)

    return 0;
}

```

- C++14에서는 `constexpr`를 사용하여 더 쉽게 작성 가능합니다. 
- constexpr 함수는 컴파일 타임과 런타임 모두 실행될 수 있습니다.
- 다음과 같은 장점이 있습니다 
	- 가독성 향상
	- 재귀 방지를 통한 컴파일 시간 향상
	- 다양한 타입 지원
	- 컴파일, 런타임 모두 지

```C++
template<typename T>
constexpr int factorial(T value) {
    T tmp = 1;
    for (int i = 2; i <= value; i++) {
        tmp *= i;
    }
    return tmp;
}

int main() {
    constexpr int x = factorial(5); // 컴파일 타임에 계산
    int y = factorial(6); // 런타임에 계산
    return 0;
}

```

### 예제) Unroll (RunTime/Compile)
- 템플릿 메타프로그래밍을 통한 반복 언롤링을합니다. 
- 일반템플릿이 재귀적으로 호출
- 특수화 템플릿으로 재귀호출 종료조
```C++
#include <iostream>
using namespace std;

// 일반 템플릿: 재귀 단계
template<int NUM_UNROLL, int STEP = 0>
struct Unroll {
    template<typename Op>
    static void run(Op op) {
        op(STEP); // 현재 스텝에 대한 작업 수행
        Unroll<NUM_UNROLL, STEP + 1>::run(op); // 다음 스텝으로 재귀 호출
    }
};

// 특수화된 템플릿: 기본 사례 (재귀 종료 조건)
template<int NUM_UNROLL>
struct Unroll<NUM_UNROLL, NUM_UNROLL> {
    template<typename Op>
    static void run(Op) {} // 더 이상 호출하지 않음
};

int main() {
    // 람다 함수: 각 스텝을 출력하는 작업
    auto lambda = [](int step) { cout << step << ", "; };
    
    // Unroll 템플릿을 사용하여 람다 함수 실행
    Unroll<5>::run(lambda); // "0, 1, 2, 3, 4, " 출력
    
    return 0;
}
```
