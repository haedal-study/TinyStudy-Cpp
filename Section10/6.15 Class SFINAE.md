- 함수 템플릿 뿐아니라 클래스 템플릿에도 SFINAE가 적용됩니다.
```C++
#include <type_traits>

template<typename T, typename Enable = void>
struct A;

// T가 부호 있는 타입일 경우
template<typename T>
struct A<T, std::enable_if_t<std::is_signed_v<T>>> {
    A() { std::cout << "signed type" << std::endl; }
};

// T가 부호 없는 타입일 경우
template<typename T>
struct A<T, std::enable_if_t<!std::is_signed_v<T>>> {
    A() { std::cout << "unsigned type" << std::endl; }
};

int main() {
    A<int> a1; // 출력: "signed type"
    A<unsigned> a2; // 출력: "unsigned type"
    return 0;
}

```
- 부호있는 타입인지,없는 타입인지에 따라, 다른 클래스 타입을 인스턴스호ㅏ 합니다.
### Class와 function Template SFINAE
- 클래스와 함수 템플릿을 함께 사용할떄도 SFINAE를 적용 가능합니다.
```C++
#include <type_traits>
#include <iostream>

template<typename T>
class A {
public:
    template<typename R = T>
    void h(R, std::enable_if_t<std::is_signed_v<R>, int> = 0) {
        std::cout << "signed" << std::endl;
    }

    template<typename R = T>
    void h(R, std::enable_if_t<!std::is_signed_v<R>, int> = 0) {
        std::cout << "unsigned" << std::endl;
    }
};

int main() {
    A<int> a1;
    a1.h(1); // 출력: "signed"

    A<unsigned> a2;
    a2.h(1u); // 출력: "unsigned"

    return 0;
}

```

- 주석처리한 부분의 경우, T가 A에 의존적이기 때문에 동작하지 않습니다.


### 구조체 맴버확인
- SFINAE는 특정 구조체가 특정 데이터 맴버 또는 타입을 가지고 있는지 확인하는 용도로도 사용가능합니다
1. 구조체 맴버 - 변수확인 (variable)
```C++
#include <type_traits>

// x 변수 확인
template<typename T, typename = void>
struct has_x : std::false_type {};

template<typename T>
struct has_x<T, decltype((void) T::x)> : std::true_type {};

// y 변수 확인
template<typename T, typename = void>
struct has_y : std::false_type {};

template<typename T>
struct has_y<T, decltype((void) std::declval<T>().y)> : std::true_type {};

```
3. 구조체 맴버 - 타입확인
```C++
template<typename...>
using void_t = void; // C++17 <utility>에 포함

template<typename T, typename = void>
struct has_type : std::false_type {};

template<typename T>
struct has_type<T, std::void_t<typename T::type>> : std::true_type {};

```
3. 스트림 연산자 지원여부 확인(support trait for stream operator)
```C++
struct A {};

is_stream_supported<int>::value; // true
is_stream_supported<A>::value; // false

```
