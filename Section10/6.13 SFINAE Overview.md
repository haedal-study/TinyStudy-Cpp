
### SFINAE : Substitution Failure Is Not An Error(SFINAE)

- 대체실패는 오류가 아니다. 라는 뜻 입니다.
- 컴파일러가 특정 타입으로 함수 템플릿을 인스턴스화 하려고 시도할 때, 이타입의 대체가 실패하면, 컴파일러는 즉시 오류를 발생시키지 않습니다. 
- 대신 특정 인스턴스화를 버리고 오버로드 집합에서 다른 유효한 후보를 찾습니다. 
- 예를들어
```C++
template<typename t>
t ceil_div(t value, t div);

template<>
unsigned ceil_div<unsigned>(unsigned value, unsigned div) {
    return (value + div - 1) / div;
}

template<>
int ceil_div<int>(int value, int div) {
    // 음수 값을 처리
    return (value > 0) && (div > 0) ? (value / div) : (value + div - 1) / div;
}

```
- 이경우에 `long long int`, `long long unsigned`, `short`, `unsigned short` 타입같은경우, 바로 컴파일 오류를 발생시키지 않고. 다양한 정입입에 대해 ceil_div함수를 처리하는 해결책을 제시합니다.

- `std::enable_if` 혹은 `std::enable_if_t` SFINE를 채택하는 일반적인 방법 중 하나입니다. 
```C++
template<bool Condition, typename T = void>
struct enable_if {
    // "type"은 "Condition == false"인 경우 정의되지 않습니다.
};

template<typename T>
struct enable_if<true, T> {
    using type = T;
};

```

위 코드를 사용하여 `ceil` 관련 예제를 다시작성하면 다음과같습니다
```C++
#include <type_traits>

template<typename T>
std::enable_if_t<std::is_integral<T>::value && std::is_unsigned<T>::value, T>
ceil_div(T value, T div) {
    return (value + div - 1) / div;
}

template<typename T>
std::enable_if_t<std::is_integral<T>::value && std::is_signed<T>::value, T>
ceil_div(T value, T div) {
    return (value > 0 && div > 0) ? (value / div) : (value + div - 1) / div;
}

```
- 부호있는 타입과 없는 타입 각각을 구분하여, 각각의 특수화를 정의하는 방식입니다.
