### `requires`
- require절과 Concepts는 템플릿 인자에 대한 제약 조건을 명시하고 강제는 기능을 제공합니다.
- 사용방법
1. concpet 정의 
	
```C++
#include <concepts>
#include <type_traits>

// Arithmetic 타입을 확인하는 Concept 정의
template<typename T>
concept Arithmetic = std::is_arithmetic_v<T>;

// Arithmetic 타입이고 크기가 4바이트 이상인 경우
template<typename T>
concept Arithmetic2 = std::is_arithmetic_v<T> && (sizeof(T) >= 4);


```

- 함수선언 뒤에 requres 절 사용합ㄴ비다.
```C++
template<typename T>
T add(T valueA, T valueB) requires (sizeof(T) == 4) {
    return valueA + valueB;
}

```

- 예제
```C++
template<typename T>
concept MyConcept = requires (T a, T b) {
    { a + b };           // 덧셈 연산자 지원
    { a[0] };            // 인덱스 연산자 지원
    { a.x };             // 멤버 변수 x 존재
    { a.f() };           // 멤버 함수 f 존재
    typename T::type;    // 내부 타입 type 존재
};

```
위내용 종합한 예제코드
```C++
#include <concepts>
#include <type_traits>
#include <iostream>

// Arithmetic 타입을 확인하는 Concept 정의
template<typename T>
concept Arithmetic = std::is_arithmetic_v<T>;

// Arithmetic 타입이고 크기가 4바이트 이상인 경우
template<typename T>
concept Arithmetic2 = std::is_arithmetic_v<T> && (sizeof(T) >= 4);

// 템플릿 파라미터 리스트 뒤에 requires 절 사용
template<Arithmetic T>
requires (sizeof(T) >= 4)
T add(T valueA, T valueB) {
    return valueA + valueB;
}

// 함수 선언 뒤에 requires 절 사용
template<typename T>
T add(T valueA, T valueB) requires (sizeof(T) == 4) {
    return valueA + valueB;
}

// requires 표현식 사용 예제
template<typename T>
concept MyConcept = requires (T a, T b) {
    { a + b };           // 덧셈 연산자 지원
    { a[0] };            // 인덱스 연산자 지원
    { a.x };             // 멤버 변수 x 존재
    { a.f() };           // 멤버 함수 f 존재
    typename T::type;    // 내부 타입 type 존재
};

int main() {
    std::cout << add(3, 4) << std::endl; // ok: 7
    std::cout << add(2.5, 3.5) << std::endl; // ok: 6.0
    // std::cout << add(A{}, A{}) << std::endl; // 컴파일 오류: A는 Arithmetic 타입이 아님

    return 0;
}

```

### require 표현식과 절을 함꼐 사용하는 경우 (1)
```C++
template<typename T>
concept Arithmetic = requires {
    T::value; // T 타입에 value 멤버가 있어야 함
    requires std::is_arithmetic_v<T>; // T 타입이 산술 타입인지 검사
};

template<typename T>
concept MyConcept = requires (T value) {
    requires sizeof(value) >= 4; // value의 크기가 4바이트 이상인지 검사
    requires std::is_floating_point_v<T>; // T 타입이 부동 소수점 타입인지 검사
};

```

### require 표현식과 절을 함꼐 사용하는 경우 (2)
```C++
template<typename T>
void f(T a) requires requires { T::value; } {
    // T 타입에 value 멤버가 있는 경우에만 인스턴스화됨
}
template<typename T>
T increment(T a) requires requires (T x) { x + 1; } {
    // T 타입이 덧셈 연산을 지원하는 경우에만 인스턴스화됨
    return a + 1;
}

```

### requre와 `constexpr`
- require와 `constexpr`를 함께사용하여 조건을 검증할 수 있습니다.
- `constexpr`를 사용하여 컴파일 타임에 검증 및하여 맴버존재여부를 검증하게됩니다
- 또한 증가연산자 지원여부또한 검증하게됩니다.
```C++
template<typename T>
constexpr bool has_member_x = requires(T v) { v.x; };

template<typename T>
constexpr bool is_incrementable() {
    return requires(T v) { ++v; };
}

struct A {
    int x;
};

struct B {};

int main() {
    static_assert(has_member_x<A>); // OK: A는 x 멤버를 가짐
    static_assert(!has_member_x<B>); // OK: B는 x 멤버를 가지지 않음
    static_assert(is_incrementable<int>()); // OK: int는 증가 연산자 지원
    static_assert(!is_incrementable<B>()); // OK: B는 증가 연산자 미지원
}

```

### Nested `requires`
- 아래 예제에서는 `Iter`타입이읽기 및 쓰기 연산은 지원하는지 검사합니다.
	- `Iter` 타입에 `value_type` 존재 여부를 검사합니다.
	- `*it` 연산이 가능해야하고, 결과가 `value_type&`과 같아야합니다.
	- `*it = v`쓰기 연산이 가능해야합니다.

```C++
template<typename Iter>
concept ReadWriteIterator = requires(Iter it) {
    typename Iter::value_type;
    *it; // 읽기
    { *it } -> std::same_as<typename Iter::value_type&>;
    requires requires(typename Iter::value_type v) {
        *it = v; // 쓰기
    };
};

```
