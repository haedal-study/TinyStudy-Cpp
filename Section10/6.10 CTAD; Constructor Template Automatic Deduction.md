- 6.10(~19/80) : CTAD; Constructor Template Automatic Deduction

### CTAD: Constructor Template Automatic Deduction
- 결론적으로, 템플릿 타입을 자동으로 유추하게하여, 코드 작성시 다양한 상황에 유연하게 대처할 수 있도록 하는것이 CTAD의 사용목적이라고 할 수 있습니다.
- C++ 17 이전에는, 아래 예제에서 `A<int, float> a1(3,4.0f)` 와 같이명시적으로 템플릿 인수를 제공하여야 했습니다.
- C++ 17 부터는 컴파일러가 템플릿 인수를 자동으로 유추 할 수 있습니다.
```C++
template<typename T, typename R>
struct A {
A(T x, R y){}
};

A<int, float> a1(3,4.0f); // C++17 이전 버전
A a2(3,4.0f) // C++17
```
### CTAD : User-Defined Deduction Guides
- 컴파일러에게 생성자 매개 변수 타입을 클래스 템플릿 파라미터로 매핑하는 방법을 지시하는 매커니즘 입니다. 
- 컴파일러가 생성자의 매개변수 타입을 템플릿 타입으로 변환하는 방법을 알려줍니다. 예를 들어, 특정 타입의 매개변수가 들어왔을 때, 이를 어떤 템플릿 타입으로 인스턴스화 할지 지정할 수 있습니다. 
``` C++
template<typename T>
struct MyString{
	MysString{
	MyString(T) {}
	}
};

MyString(char const*) -> MyString<std::string>;
MyString s{"abc"}; 
```

#### 집계함수 예제
```C++
template<typename T>
struct A {
	T x,y;
};

template<typename T>
A(T,T) -> A<T>; //deduction guide
A a{1,3}
```
