
- 6.11(~29/80) : Class Template - Advanced Concepts

### 1. Specialization - 템플릿 특수화
- 템플릿 특수화로, 특정 타입이나 조건에 따라 템플릿의 동작을 맞춤화 할 수 있습니다.
```C++
template<typename T, typename R>
struct A {
    template<typename X, typename Y>
    void f();
};
```

- 위처럼 클래스 템플릿과, 템플릿 멤버 함수가 있을때, 클래스/함수를 특수화하는 방법은 두가지 있습니다.
	1. 일반클래스 + 일반함수 (Generic class + generic function)
	2. 전체클래스 특수화 + 일반/전체 특수화 함수 (Full class specialization)
```C++
template<typename T, typename R>
template<typename X, typename Y>
void A<T, R>::f() {} // ok, A<T, R>와 f<X, Y>는 특수화되지 않음
```

```C++ 
template<typename T, typename R>
template<typename X, typename Y>
void A<int,int>::f(){}
```
- A<int, int>는 전체특수화가 됩니다.
- f()는 특수화되지 않습니다
```C++
template<>
template<typename X, typename Y>
void A<int,int>::f(){}
```
- 위의 경우에는 `A<int,int>`와 `f<int,int>` 모두 특수화됩니다.
##### 에러사레 
```C++
template<typename T>
template<typename X, typename Y>
void A<T, int>::f() {} 
```
- **부분 특수화된 클래스는 미리 정의되어야 합니다.**
- `A<T,int>`는 부분 특수화된 클래스 입니다. 그러나 부분 특수화된 클래스는 미리 정의되어야 하로 에러가 발생합니다. 
-------------

```C++
template<typename T, typename R>
template<typename X>
void A<T, R>::f<int, X>() {} // error 함수 멤버는 부분 특수화될 수 없음
```
- **함수 맴버는 부분특수화 될 수 없습니다.
- 즉 일부 템플릿 인수만을 특수화 하는 것은 허용되지 않습니다. 
------- 

```C++
template<typename T, typename R>
template<>
void A<T, R>::f<int, int>() {} // error 비특수화된 클래스의 함수 멤버는 특수화될 수 없음 (컴파일 타임에 특정 템플릿 인스턴스화가 필요함)
```
- 비특수화된 클래스 `A<T,R>`의 함수 멤버는 특수화 될 수 없습니다.
- 이는 컴파일 타임에 특정 템플릿 인스턴스화가 필요하기 때문입니다.
### 2. Accessing a Dependent Type - `typename` keyword
```C++
// 참고 type이 정적멤버인경우 
template<typename T>
struct A {
	static const int type =42;
};

template<typename R>
void h(){
int x = B<R>::type;
}
```
`typename` Keyword - 의존타입 접근, typename 키워드
- 구조체 템플릿은, 각 특수화에 대해서 서로 다른 데이터 멤버를 가질 수 있습니다.
- 컴파일러는 구조체 템플릿이 다른 템플릿 매개변수에 의존할 때, 구조체 내의 심볼이 **타입인지 정적멤버인지 미리 알아야합니다.**
- `typename`키워드로 이 모호함을 해결할 수 있습니다.
- 예시 - 아래와 같은경우, `A<R>::type`이 타입인지 정적 멤버(static member) 인지 알기 어려워 혼동 될 수 있습니다.
```C++
template<typename T>
struct A {
using type = int;
};

template<typename R>
void g(){
using X = A<R>::type;
}
```

```C++
template<typename R>
void g(){
using X = typename A<R>::type;
}
```

- using을 사용하여 더 단순화 할 수 있습니다
``` C++
template<typename T>
struct A {
    using type = int;
};

template<typename T>
using AType = typename A<T>::type;

template<typename R>
void g() {
    using X = AType<R>; // 더 간결한 표현
}

```
### 3. Template Dependent Names - `template` Keyword
- 템플릿 의존 이름 (Template Dependent Names)란, 탬플릿 매개 변수에 의존하는 이름을 의미합니다.
- `template` 키워드는 컴파일러에게 뒤에 오는것이 템플릿 이름임을 명확히 알리는 역할을 합니다.
-  최신 컴파일러의 경우 키워드를 엄격히 요구하지 않을 수도 있으나, 명확히 하기위해 `template` 키워드를 사용하는것이 좋습니다. 
```C++
template<typename T>
struct A {
    template<typename R>
    void g() {}
};

template<typename T>
void f(A<T> a) {
    // a.g<int>(); // 컴파일 에러: g<int>는 의존 이름(dependent name)
    // "(a.g < int) > ()"로 해석됨

    a.template g<int>(); // 올바름: g가 템플릿 함수임을 명시적으로 알려줌
}

```
### 4. Class Template Hierarchy  and `using`
- 클래스 템플릿 계층구조에서, 파생클래스가 기반 클래스의 특정타입을 내부적으로 사용하는 경우, `using` 키워드를 사용하여 이를 명확히 지정할 수 있습니다.
- 이를 사용해 다른 특수화와 혼동을 방지하는데 사용될 수 있습니다.
- 예제
	- 아래 예제에서, 파생클래스 B는 A를 상속받기에, A의 멤버 x와 f를 상속받습니다. 
	- 하지만 이를 x와 f를 기반클래스 멤버로 명확하기 지정하기 위해 `using`키워드를 사용해야합니다. 
	- 이렇게 명확히 지정하여, 다른 특수화된 멤버와의 혼동을 방지합니다.
```C++
template<typename T>
struct A {
    T x;
    void f() {}
};

template<typename T>
struct B : A<T> {
    using A<T>::x; // 기반 클래스 A<T>의 멤버 x를 명시적으로 사용
    using A<T>::f; // 기반 클래스 A<T>의 멤버 f를 명시적으로 사용

    void g() {
        x; // using 없이 this->x로 접근해야 함
        f(); // using 없이 this->f()로 접근해야 함
    }
};

```
### 5. `virtual`Function and Template 
- 가상함수는 템플릿 인수를 가질 수 없습니다.
	- 템플릿은 컴파일타임에 동작합니다.
	- 가상함수는 런타임에 동작하는 기능입니다.
- 이 두기능이 결합이 불가능한 이유는, 무한한 수의 템플릿 인스턴스화 가능성 때문입니다.
- 이는 컴파일러가 이러한 많은 타입을 동적으로 디스패치 하는 코드를 생성해야하며, 이는 실현 불가능합니다. (take turns, turns out)
- 참고: 가상 함수와 템플릿을 분리하여, 사용하는 대안
```C++
#include <iostream>

// 가상 함수가 있는 기반 클래스
struct Base {
    virtual void f() = 0; // 순수 가상 함수
};

// 파생 클래스는 가상 함수를 구현
struct DerivedInt : Base {
    void f() override {
        std::cout << "DerivedInt::f" << std::endl;
    }
};

struct DerivedDouble : Base {
    void f() override {
        std::cout << "DerivedDouble::f" << std::endl;
    }
};

// 템플릿을 사용하여 파생 클래스를 생성
template<typename T>
Base* create() {
    if constexpr (std::is_same_v<T, int>) {
        return new DerivedInt();
    } else if constexpr (std::is_same_v<T, double>) {
        return new DerivedDouble();
    } else {
        return nullptr;
    }
}

int main() {
    Base* b1 = create<int>();
    b1->f(); // DerivedInt::f 호출

    Base* b2 = create<double>();
    b2->f(); // DerivedDouble::f 호출

    delete b1;
    delete b2;

    return 0;
}

```
### 6. `friend` Keyword
- `friend`키워드를 사용하여, 클래스 내부에서 다른 클래스나 함수를 `friend`로 선언하고 해당 클래스의 비공개 멤버에 접근할 수 있도록 합니다.
- **템플릿과 함께 사용시, 특정 템플릿 인스턴스나, 템플릿 자체를 친구로 선언할 수 있습니다.**
```C++
template<typename T>
struct A {};

template<typename T, typename R>
struct B {};

template<typename T>
void f() {}

//----------------------------------------------------------------------------------

class C {
    friend void f<int>();// 특정 함수 인스턴스를 친구로 선언, 오직 f<int>()만 접근 가능
    template<typename T> friend void f(); // 모든 함수 템플릿 인스턴스를 친구로 선언
    friend struct A<int>;               // 특정 템플릿 클래스 인스턴스를 친구로 선언
    template<typename> friend struct A; // 모든 템플릿 클래스 인스턴스를 친구로 선언
    // template<typename T> friend struct B<int, T>; // 부분 특수화는 친구로 선언할 수 없음
};
```

- 내가 `friend`개념이 이해가 잘 안가서 만든 예제
```C++
#include <iostream>

class C {
private:
    int secret = 42; //friend로 맴버변수 선언할수는 없음

    // 특정 함수 인스턴스를 친구로 선언
    friend void revealSecret(C& c);
};

void revealSecret(C& c) {
    std::cout << "Secret: " << c.secret << std::endl; // 비공개 멤버에 접근 가능
}

int main() {
    C obj;
    revealSecret(obj); // 비공개 멤버에 접근하는 친구 함수 호출
    return 0;
}

```
### 7. Template template Arguments

- 템플릿 템플릿 인수란, 구체적인 타입대신 **템플릿을 인수로 받는 템플릿입니다.**
- 템플릿 매개변수로 다른 템플릿을 전달할 수 있게 합니다.
- C++17에서는 `class`와 `typename` 키워드를 상호 교환 하여 사용할 수 있습니다.
```C++
template<typename T>
struct A {};

template< template<typename> class R >
struct B {
    R<int> x;   // R 템플릿의 int 타입 인스턴스
    R<float> y; // R 템플릿의 float 타입 인스턴스
};

template< template<typename> class R, typename S >
void f(R<S> x) {
    // R 템플릿의 S 타입 인스턴스를 매개변수로 받음
}

B<A> y; // B는 A 템플릿을 인수로 받음
f(A<int>()); // A<int> 타입의 인스턴스를 함수 f에 전달
```
- B<A>는 A템플릿을 인수로 받으며, f함수는 `A<int>` 타입의 인스턴스를 매개변수로 받습니다.
