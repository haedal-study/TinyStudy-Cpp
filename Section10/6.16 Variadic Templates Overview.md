### Variadic Template(가변 인자 템플릿)
- C++11 에서 도입된 기능으로, 임의 개수의 인자를 받는 템플릿을 말합니다.
	- 코드의 유연성과 재사용성을 높일 수 있습니다. 
- 이러한 템플릿은 다양한 타입의 인자를 받을 수 있습니다.
```C++
template<typename... TArgs> // Variadic typename
void f(TArgs... args) { // Typename expansion
    // 함수 내용
}

```
- TArgs는 템플릿 파라미터 팩을 나타내며, 
- args는 함수 매개변수 팩을 나타냅니다.
- `sizeof..(args)`를 이용하여 가변인자의 개수를 얻을 수 있습니다. 

#### 예제

기본케이스
```C++
template<typename T, typename R>
auto add(T a, R b) {
 return a + b;
}
```

재귀케이스
```C++
template<typename T, typename... TArgs> // Variadic typename
auto add(T a, TArgs... args) { // Typename expansion
    return a + add(args...); // Arguments expansion
}
```
구현
```C++
add(2, 3.0); // 5
add(2, 3.0, 4); // 9
add(2, 3.0, 4, 5); // 14
// add(2); // compile error - 기본 케이스는 두 개의 인자만 받습니다
```

#### 예제2 - Parameter type

```C++
template<typename... TArgs>
void f(TArgs... args) {} // pass by-value

template<typename... TArgs>
void g(const TArgs&... args) {} // pass by-const reference

template<typename... TArgs>
void h(TArgs*... args) {} // pass by-pointer

int* a, *b;
f(1, 2.0);
h(a, b);


```

#### 예제3 -Function Application
```C++
template<typename T>
T square(T value) {
    return value * value;
}

template<typename T, typename R>
auto add(T a, R b) {
    return a + b;
}

// 기본 케이스
template<typename T, typename... TArgs>
auto add(T a, TArgs... args) {
    return a + add(args...);
}

//-----------------------------------------------------------

template<typename... TArgs>
auto add_square(TArgs... args) {
    return add(square(args)...); // square()가 각 인자에 적용됨
}

// 사용 예제
add_square(2, 2, 3.0f); // 결과: 17.0f

```
#### 예제4- Arguments to Array
```C++
template<typename... TArgs>
void f(TArgs... args) {
    constexpr int Size = sizeof...(args);
    int array[] = {args...};
    for (auto x : array) {
        std::cout << x << " ";
    }
    std::cout << std::endl;
}

// 사용 예제
f(1, 2, 3); // 출력: "1 2 3"
f(1, 2, 3, 4); // 출력: "1 2 3 4"

```
- 위 예제에서, variadic template 인자들을 배열로 변환하여 순회하는 방법을 보여줍니다.
