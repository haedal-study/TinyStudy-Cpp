
### Function SFINE
함수 SFNAE는 다음과같은 종류가 있습니다



### 1. Return Type
- 아래 예제에서는 `std::is_signed_v<T>` 조건에 따라 부호있는 타입인지 없는 타입인지 판단하여, 각각 다른함수를 호출합니다. 
```C++
#include <type_traits> // std::is_signed_v, std::enable_if_t

template<typename T>
std::enable_if_t<std::is_signed_v<T>> f(T) {
    std::cout << "signed";
}

template<typename T>
std::enable_if_t<!std::is_signed_v<T>> f(T) {
    std::cout << "unsigned";
}

f(1); // 출력: "signed"
f(1u); // 출력: "unsigned"
```
### 2. Parameter
- 아래 예제에서는 `std::enable_if_t`를 매개변수로 사용하여 SFINAE를 적용합니다.
- 매개변수 타입이 부호있는 타입인지 없는타입인지에 따라 다른 함수를 호출합니다. 
```C++
#include <type_traits>

template<typename T>
void f(std::enable_if_t<std::is_signed_v<T>, T>) {
    std::cout << "signed";
}

template<typename T>
void f(std::enable_if_t<!std::is_signed_v<T>, T>) {
    std::cout << "unsigned";
}

f(1); // 출력: "signed"
f(1u); // 출력: "unsigned"

```

### 3. Hidden Parameter
- 숨겨진 매개변수를 사용하여 SFINAE를 적용합니다.
- 함수 호출 시 기본 매개 변수로 `std::enable_if_t`를 사용하여 부호있는 타입과 부호 없는 타입을 구분합니다.
```C++
#include <type_traits>

template<typename T>
void f(T, std::enable_if_t<std::is_signed_v<T>, int> = 0) {
    std::cout << "signed";
}

template<typename T>
void f(T, std::enable_if_t<!std::is_signed_v<T>, int> = 0) {
    std::cout << "unsigned";
}

f(1); // 출력: "signed"
f(1u); // 출력: "unsigned"

```

### 4. Hidden Template Parameter
- 숨겨진 템플릿 매개변수를 사용하여 SFINAE를 적용합니다.
- 템플릿 매개변수로 `std::enable_if_t`를 사용하여 부호있는 타입과 부호 없는 타입을 구분합니다.
```C++
#include <type_traits>
template<typename T, std::enable_if_t<std::is_signed_v<T>, int> = 0>
void f(T) {
    std::cout << "signed";
}

template<typename T, std::enable_if_t<!std::is_signed_v<T>, int> = 0>
void f(T) {
    std::cout << "unsigned";
}

f(4); // 출력: "signed"
f(4u); // 출력: "unsigned"
```
### 5. `decltype` + return type
- delctype과 std::enable_if_t를 사용하여 함수의 **반환타입에따라 SFINAE를적용**
- 첫번째는 두 타입의 합 연산이 가능한 경우를 처리하고, 두 번째 템플릿은 첫번째 타입이 클래스인 경우를 처리합니다. 
```C++
#include <type_traits>

template<typename T, typename R> //(1)
decltype(T{} + R{}) add(T a, R b) {
    return a + b;
}

template<typename T, typename R> // (2)
std::enable_if_t<std::is_class_v<T>, T> add(T a, R b) {
    return a;
}

struct A {};

add(1, 2u); // (1) 호출
add(A{}, A{}); // (2) 호출

```
### 6. Array vs Pointer
```C++
#include <type_traits>

template<typename T, int Size>
void f(T (&array)[Size]) {} // (1)

//template<typename T, int Size>
//void f(T* array) {} // (2)

template<typename T>
std::enable_if_t<std::is_pointer_v<T>> f(T ptr) {} // (3)

int array[3];
f(array); // (1) 호출


```
- 여기서는 배열과 포인터를 구분하기 위해 SFINAE를 사용합니다.
- (2) 가 주석 해제되어있는경우, 배열이 포인터로 해석되어 (1)이 호출되지 않을 것입니다.
